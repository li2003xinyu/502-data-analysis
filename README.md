# 502-data-analysis
## 项目简介
本项目针对推力器地面热试车数据，应用多变量时间序列分析与数据挖掘手段，获取推力器关键特性（推力、流量、燃压、混合比等）与入口推进剂压力、温度、点火时间之间的内在关联。

## 研究目标
1. **多源数据预处理**：完成 5kHz 高频信号与 10Hz 低频温度信号的时序对齐与特征提取。
2. **关联关系建模**：挖掘推力/混合比与氧/燃喷前压、推进剂温度的映射关系。
3. **阶段特征分析**：区分“启动段、稳态段、关机热回浸段”的参数响应差异。
4. **可解释性挖掘**：量化参数重要性排序及交互效应。

## 目录结构
- `data/`：脱敏样例数据
- `src/`：核心算法源码与特征工程脚本
- `notebooks/`：数据探索性分析 (EDA) 与模型原型
- `results/`：模型评估指标、图表与分析结果
- `docs/`：相关交付文档与使用说明
