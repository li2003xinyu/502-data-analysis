# 502-data-analysis
## 项目简介
本项目针对推力器地面热试车数据，应用多变量时间序列分析与数据挖掘手段，获取推力器关键特性（推力、流量、燃压、混合比等）与入口推进剂压力、温度、点火时间之间的内在关联。

## 研究目标
1. **多源数据预处理**：完成 5kHz 高速采集与 10Hz 低速采集数据的时序对齐与清洗。
2. **分段特征提取**：结合推力器点火物理过程（启动、稳态、关机热回浸），提取反映参数动态响应的关键特征。
3. **关联挖掘与建模**：应用多变量时间序列分析与机器学习方法，构建关键特性与入口参数的映射模型。
4. **可解释性分析**：量化参数重要性排序及交互效应，深入剖析参数间的非线性关联。

## 目录结构
- `data/`：脱敏样例数据
- `src/`：核心算法源码与特征工程脚本
- `notebooks/`：数据探索性分析与模型原型
- `results/`：模型评估指标、图表与分析结果
- `docs/`：相关交付文档与使用说明
